# 桌面组件编辑

在设置的「组件与主界面 → 组件布局」中，每行按照桌面上从左到右的顺序排列。点击组件可在右侧修改该实例；同类型的文本组件显示各自的正文，隐藏的组件也可以再次选中。在行尾点「＋」打开该行的组件库，或从库里拖到组件前后插入。拖动现有组件可以调整行内顺序或移到另一行。较宽的行可以横向滚动，窄窗将属性区放到行条下方；「顺序列表」提供纵向排列、上移、下移以及相同的检查器。

「所在行 → 移到新的一行」可以新建一行，移走最后一个组件会收起空行。「布局方案」保存命名的本机排列，可在多个布局间切换；管理菜单支持新建、保存副本、重命名和删除未启用的方案，不改变课表文件。切换前会提交仍在编辑的文本和滑块值。若方案文件受损，仍可调整当前桌面，点「备份并恢复」并确认后才会保留损坏原件、从当前桌面建立默认方案。

「显示时段」可以为每个组件单独选择始终显示、仅上课、仅课间、仅活动或仅当天无课。当天无课指整天没有课程（包括临时停课），不是当前课已经下课。当天临时作息优先；课间内安排了活动时，显示活动组件，活动结束后再显示课间组件。进入桌面编辑时能找回被条件隐藏的实例；退出后，空的行和多余的分隔线会收起。如果所有组件都只是暂时不显示，空蒙版不会留下来挡住鼠标，提醒和 NEX 仍然可用。

「布局与外观」默认折叠。宽度留空时由内容决定，固定宽度优先于宽度范围。对齐、四边留白、底色、底色透明度、圆角和整个组件的透明度分别保存；最后两种透明度不会改动课表蒙版或其他组件。「恢复默认」只清除该实例的自定义外观，不会重置组件列表或覆盖文字。修改已显示的实例不必重新打开浮窗。

桌面进入编辑模式后，拖动组件名称可将它放到另一组件所在的位置；组件齿轮就地打开该实例的属性面板。面板提供常用的字号、透明度与该类型的选项，「全部组件设置」打开同一实例的设置页。编辑栏的「桌面外观」可就地预览整个浮窗的缩放和底色透明度；各组件「更多」中的所在行操作可以移到现有行或新建一行。无法拖动时，设置里的上下移动和所在行选择器也可完成排序。

## 与 ClassIsland 2.x 的对应范围

核对本地 ClassIsland `235914a2fac1` 的 `ComponentsSettingsPage`、`EditModeView`、`EditableComponentsListBox` 和 `ComponentSettings`。仅对照流程和数据含义；编辑器仍为 ClassNEX 原生 WinUI 和 Avalonia 控件。

| 对应能力 | ClassNEX 的实现 |
| --- | --- |
| 分行、顺序、显示状态和独立副本 | 按真实行横排，保留键盘可用的顺序列表；同类型文本可以保存不同内容。 |
| 命名的组件布局 | 本机方案保存组件及其属性；原来的配置不需要手动转换即可继续使用。 |
| 指定时段显示 | 上课、课间、活动和当天无课是内置、只读的课表条件；可在每个组件上独立设置。 |
| 版面、背景和组件透明度 | 复用现有 `WidgetPresentation`，包括迁移进来的可选值；无自定义外观时不额外包裹原控件。 |
| 桌面编辑和设置检查器 | 桌面齿轮提供即时编辑，完整设置在选中实例的检查器中；支持鼠标拖放和键盘排序。 |
| 仍有差异 | 没有 ClassIsland 的嵌套容器、自定义多条件规则组合、插件专属编辑器或各行独立的整套主题。字体、控件和动画也不宣称像素级一致。 |

`tools/verify_settings.ps1` 在匿名配置中核对实际设置控件、浮窗包装、持久化、齿轮面板和拖动落点。`widget-input-path.txt` 记录每次实际采用的输入路径：目标窗口的 Win32 消息或 Avalonia 的命中测试及指针捕获。两者都不是物理鼠标或触摸屏测试；也不能据此声称 Windows OLE 从组件库跨控件拖入已经在真实硬件验收。
