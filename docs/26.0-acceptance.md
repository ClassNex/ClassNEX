## 交付了什么

- Core 独立于 Avalonia：CSES 与单双周、课程查询缓存、设置及公共契约。新配置获得默认组件；用户主动清空的布局、设置成 55% 的不透明度和旧版便携目录下已编辑的课表不会在启动时被重置。Core 的本地 NuGet 包包含 DLL、README 和公开 API 的 XML 文档；未推送 NuGet。
- 提醒服务拆出队列、优先级、过期与去重，由桌面渠道展示。课前和下课提醒显示课程全名；两页提示间隔十秒。退出提醒按当前组件实际尺寸恢复背景。隐藏、编辑和 NEX 对话时互不抢占。
- 插件宿主独立发现、检查版本和依赖，启停只影响对应依赖链。错误、加载状态和权限在设置中可见。进程内插件是**可信代码**，权限声明不是安全沙箱；[开发协议](PLUGIN_SDK.md)列有旧 Alpha 的兼容规则。
- 桌面课表保留时间、单双周、当前/下一节、剩余时间、组件编辑和拖动。设置提供统一导航、搜索与返回、深浅/系统主题。账号、集控与 NEX 保留各自独立的业务入口。调色、卡片、输入和开关复用现有 AvaloniaFluentUI 资源；没有改换技术栈或复制参考项目的素材。
- 登录使用系统浏览器和 PKCE，集控登录回到 `/Control/`，支持双向自动同步。下发设置不替换本机账号、密钥、路径或权限。旧版嵌入的公用 NEX 密钥已从此分支移除，使用本人配置的密钥或为内置端点设置 `CLASSNEX_NEX_API_KEY`。历史包保持原样，旧密钥需要在供应商端轮换。
- 上一份候选包在关闭未完成的欢迎向导时以 `0xC00000FD` 退出，已排除。修复后首次向导由桌面生命周期负责退出；从设置重看向导只关闭预览。麦克风在向导期间不会自行启动，原先的占位步骤可直接选择是否使用语音唤醒。移除了完成页持续运行的粒子效果。

## 复测

在仓库根目录使用 PowerShell，窗口验收的轮次名称必须之前未使用：

```powershell
dotnet restore ClassNex.sln
dotnet build src/ClassNex/ClassNex.csproj -c Debug -t:Rebuild
dotnet build ClassNex.sln -c Debug --no-restore
dotnet test ClassNex.sln -c Debug --no-build
./tools/review_desktop.ps1 -Round classroom-review-01
./tools/test_alpha_binary.ps1
py -3 tools/test_central_oauth.py --desktop src/ClassNex/ClassNex.csproj
dotnet package list --project ClassNex.sln --vulnerable --include-transitive
dotnet pack src/ClassNex.Core/ClassNex.Core.csproj -c Release -o build/core-sdk
```

便携包使用 PowerShell 7 和 Python 3.11+ 复测。对本次交付的 ZIP，`$sha512` 使用上方公开值；本地重新打包应使用该次构建记录的校验值（ZIP 条目时间可以不同）。`$zipPath` 为要验证的文件。此流程不打标签，不发布 Release。

```powershell
./tools/package_refactor_candidate.ps1 -SourceCommit 4f2e6677a75f6ba9dd5edc9e57eca61a9a922e05
py -3 tools/verify_portable.py $zipPath
./tools/test_portable_startup.ps1 -Archive $zipPath -ExpectedSha512 $sha512 -ReviewedPristineSource 4f2e6677a75f6ba9dd5edc9e57eca61a9a922e05
```

上线前仍需在目标教室验证真实 Casdoor/上游网络、麦克风识别和物理投屏；本轮不代表这些现场条件已通过。
