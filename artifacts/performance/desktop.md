# Windows 课表浮窗：空闲进程对照

2026-11-22，在同一台 Windows 11（build 26200，8 个逻辑处理器）上比较 `26w46d_Alpha`（`60d7b57`）和重构版（`4ea188d`）。本次四次独立启动中，重构版的空闲 CPU、私有字节和工作集均低于 Alpha。测量先于首次启动向导退出修复 `4f2e667`；没有对该修复后的版本重新采样，也没有测试全天驻留、整机占用或帧率。

| 启动顺序 | 版本 | 采样秒 | 进程 CPU 秒 | CPU（单核 = 100%） | 私有字节中位数 | 工作集中位数 |
| ---: | --- | ---: | ---: | ---: | ---: | ---: |
| 1 | Alpha | 30.014 | 3.672 | 12.23% | 99.27 MiB | 214.27 MiB |
| 2 | 重构 | 30.017 | 2.391 | 7.96% | 95.80 MiB | 211.09 MiB |
| 3 | 重构 | 30.014 | 1.781 | 5.93% | 94.88 MiB | 210.02 MiB |
| 4 | Alpha | 30.008 | 2.672 | 8.90% | 104.78 MiB | 219.59 MiB |

两轮等权平均：单核 CPU **10.57% → 6.95%**（少 3.62 个百分点），私有字节 **102.02 → 95.34 MiB**，工作集 **216.93 → 210.55 MiB**。私有字节是进程私有提交量，工作集包括驻留的共享页，两者不能相加。CPU 由进程累计处理器时间除以实际采样时长计算，不是任务管理器按整机容量折算的百分比。

## 条件与复现

- 本轮的 Alpha 来自 Git 标签导出，重构版使用当时复制的工作区快照。事后将实际参与构建的两个目录分别与对应提交的 `git archive` 独立比对：Alpha 的 127 个文件逐字节相同；候选的 144 个文件中，100 个逐字节相同，44 个只有 CRLF/LF 差异，没有新增或缺失文件。表中 CPU 及两项内存中位数亦已从 64 个原始采样点复算。
- 两版都用 .NET SDK 10.0.401 在独立 `--artifacts-path` 下发布框架依赖的 x64 Release，并使用相同的本机 .NET 10 运行时。不使用既有调试二进制，不复用任何一个用户配置目录。
- 每次启动有自己的匿名便携目录。同一份七天合成课表，每天两节课；浅色，仅启用「日期」「课表」两组件，缩放 1.35，鼠标穿透；不打开设置，不启动通知、集控、NEX 唤醒或边缘唤醒条。不加载用户插件、账户或密钥。四份初始课表 SHA-256 一致，均未产生账户文件或崩溃日志。
- 两版都启用置顶。预检发现 Alpha 会自行恢复置顶，而重构版遵守关闭设置；上表不混用预检结果。仅启动应用自带的浮窗，未切换窗口、注入输入、调用麦克风或手动触发 GC、清理工作集。
- 按 Alpha → 重构 → 重构 → Alpha 交错启动同一显示环境中的新进程。每次预热 15 秒，随后每 2 秒读取进程计数器，共 16 个采样点。每轮结束只终止自己的测试实例。两轮波动可见，机器上的其他活动未锁定；没有做置信区间推断。未测长课时泄漏、GPU/DWM 消耗、有声唤醒、设置打开或通知播放。
- 复测本轮版本：`pwsh -NoProfile -File tools/measure_idle.ps1 -CandidateCommit 4ea188deb895e44debdde324ae3b84b2e5ed08fe`。省略 `-CandidateCommit` 时使用启动脚本时的 `HEAD`。脚本先校验固定的 Alpha SHA 和候选的祖先关系，再从两个完整提交 SHA 分别执行 `git archive`；未提交文件不会进入构建。可加 `-Pairs 4 -SampleSeconds 120` 做更长的复测。
- 每次新建 `build/idle-performance-<id>/results.json`，保存实际秒数、每个样本、源码摘要和版本；本轮 ID 为 `ff6b92a1b3094a0d912961c996fa7374`。采样脚本见 [measure_idle.ps1](../../tools/measure_idle.ps1)，课表查询微基准另见 [schedule.md](schedule.md)。
