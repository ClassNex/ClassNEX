# 首次启动向导：实窗对照

[改前录屏](before.gif) · [改后录屏](after.gif)。两份均来自同一台 Windows 电脑，只录匿名测试进程的向导窗口，不录桌面。改前是 `4f2e667` 的向导；改后是合入主线的客户端。

| 同口径指标 | 改前 | 改后 |
| --- | ---: | ---: |
| 从向导 `OnOpened` 到首次绘制回调 | 317 ms | 171 ms |
| 到欢迎文字可读（不透明度 ≥ 0.75） | 832 ms | 172 ms |
| 到底部按钮可读且可操作（同一阈值） | 877 ms | 173 ms |
| 首次绘制回调时，文字和按钮是否均达标 | 否 | 是 |
| 窗口采集时段（图像样本数） | 5.00 秒（50） | 3.35 秒（28） |

表中计时取自两段录屏对应的运行日志，不是进程冷启动耗时，也不是显示帧率。另在旧宿主中仅替换向导复测：旧版文字和按钮分别在 1123、1204 ms 达标，新版均为 306 ms。旧版固定等待 450 ms 后才逐帧淡入；新版先显示中文和可用按钮，插画随后在后台解码。

| 改后实测路径 | 结果 |
| --- | --- |
| 正常完成五步 | 前进和返回均可用；连点不会跳过步骤，双击“完成”只启动一个新进程。新进程实际显示“ClassNEX 主界面”，所选开学日期已保存，语音仍关闭。 |
| 首屏直接关闭 | 进程正常退出，未写入向导完成标记。 |
| 减少动画 | 仅在匿名 Debug 向导中启用与系统关闭动画相同的分支；五步均可达，问候保持中文，关闭后未保存临时切换的语言、主题或开机自启。 |
| 延后启动服务 | 首屏和最后一步均未构造课堂浮窗、通知、插件或集控；访问账户页未发起浏览器授权，完成前未创建麦克风协调器。 |

这些测试没有更改 Windows 的动画设置或开机自启注册表项，也未使用真实账户或麦克风。

复测：先完整重建 Debug 客户端，再用 PowerShell 运行 [`tools/review_oobe_motion.ps1`](../../../tools/review_oobe_motion.ps1)，分别传入 `-Mode finish`、`-Mode close` 和 `-Mode reduced`。录屏时额外传入 `-RecordingPython` 指向已安装 Pillow 的 Python 解释器。
